# Task Scheduler\n\nA Python task scheduler with a deadline heap, dispatcher thread, fixed worker pool, cancellation, recurring tasks, and runtime metrics.\n\n## Features\n\n- Delayed task execution with monotonic time\n- Priority ordering by deadline\n- Fixed-size worker pool\n- Task result and exception propagation\n- Cooperative cancellation\n- Recurring tasks and scheduler metrics\n\n## Architecture\n\nThe dispatcher waits for the nearest deadline and moves due work from a heap into a thread-safe queue. Workers consume that queue and run functions in parallel.\n\n## Usage\n\n```python\nfrom scheduler import TaskScheduler\n\nscheduler = TaskScheduler(worker_count=2)\ntry:\n    handle = scheduler.schedule(lambda: 2 + 3, delay=1)\n    print(handle.result())\nfinally:\n    scheduler.shutdown()\n```\n\n## Test\n\n```powershell\npython -m pip install pytest\npython -m pytest\n```\n\n## Design tradeoffs\n\nCancellation prevents a pending task from starting, but Python cannot safely force-stop a task already running on another thread.\n
